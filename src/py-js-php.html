Python vs JavaScript vs PHP Syntax Reference

Feature Python JavaScript (ES6+) PHP (8+)
Variables & String Concatenation 
name = "Alice"
age = 30
greeting = "Hello " + name
is_active = True
empty = None
No keywords needed; uses capitalization for True/False/None. 
const name = "Alice";
let age = 30;
let greeting = `Hello ${name}`;
let isActive = true;
let empty = null;
Requires block-scope keywords (let/const); template literals support variables directly inside strings. 
$name = "Alice";
$age = 30;
$greeting = "Hello " . $name;
$isActive = true;
$empty = null;
All variables must start with a $ symbol; uses a dot (.) for concatenation.
Conditionals (If / Else) 
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
Strict indentation defines the code blocks instead of brackets. 
if (score >= 90) {
    console.log("A");
} else if (score >= 80) {
    console.log("B");
} else {
    console.log("C");
}
Requires brackets around conditions and curly braces around blocks. 
if ($score >= 90) {
    echo "A";
} elseif ($score >= 80) {
    echo "B";
} else {
    echo "C";
}
Requires brackets and curly braces; "elseif" is written as a single word.
Arrays & Key-Value Pairs 
# Ordered List
fruits = ["apple", "banana"]
fruits.append("cherry")

# Dictionary
user = {"name": "Bob", "age": 25}
print(user["name"])
 
// Ordered Array
const fruits = ["apple", "banana"];
fruits.push("cherry");

// Object Literal
const user = { name: "Bob", age: 25 };
console.log(user.name);
 
// Indexed Array
$fruits = ["apple", "banana"];
$fruits[] = "cherry"; 

// Associative Array
$user = ["name" => "Bob", "age" => 25];
echo $user["name"];
Loops 
# For range
for i in range(0, 3):
    print(i)

# Iteration
for fruit in fruits:
    print(fruit)
 
// Counter loop
for (let i = 0; i < 3; i++) {
    console.log(i);
}

// Iteration
for (let fruit of fruits) {
    console.log(fruit);
}
 
// Counter loop
for ($i = 0; $i < 3; $i++) {
    echo $i;
}

// Iteration
foreach ($fruits as $fruit) {
    echo $fruit;
}
Functions 
def add(a, b=10):
    return a + b

result = add(5)
 
function add(a, b = 10) {
    return a + b;
}

// Arrow syntax
const add = (a, b = 10) => a + b;
 
function add($a, $b = 10) {
    return $a + b;
}

$result = add(5);
Classes & OOP 
class User:
    def __init__(self, name):
        self.name = name

    def greet(self):
        return f"Hi, {self.name}"

user = User("Alex")
 
class User {
    constructor(name) {
        this.name = name;
    }
    greet() {
        return `Hi, ${this.name}`;
    }
}
const user = new User("Alex");
 
class User {
    public string $name;

    public function __construct($name) {
        $this->name = $name;
    }
    public function greet(): string {
        return "Hi, " . $this->name;
    }
}
$user = new User("Alex");
